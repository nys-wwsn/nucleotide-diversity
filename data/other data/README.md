# other  data folder

This folder contains additional data used in the nucleotide diversity calculation and data preparation steps.

## County_Region.csv

This file contains NYS region names, region populations, county names, and county populations.

## erie_NY029028410A.rds

This file contains the windowed diversity values for one treatment plant in Erie County (Bird Island WWTP).

## lineage name files.Rdata

This R data file contains the lineage names and variants of concern list as reported by the CDC Nowcast and WHO.

## nys-wws-sewersheds.csv

This file contains the metadata for each sampling site in NY.

## onondaga_NY067027723A.rds

This file contains the windowed diversity values for one treatment plant in Onondaga County (Meadowbrook and Limeston WWTP).

## sars2_concentration.rds

This file contains the wastewater concentration data for each sampling site.
